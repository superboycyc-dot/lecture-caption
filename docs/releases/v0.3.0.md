## Lecture Caption v0.3.0

First public open-source release. / 首次公开开源发布。

- English/Chinese floating lecture captions from microphone or system audio.
- Live Markdown notes for CS/math lectures, plus retained source text.
- Blue/white icon and UI, independent Pin and opacity controls.
- macOS Keychain credential storage; no local AI model inference.
- Independent macOS Apple Silicon application with bundled runtime.

### Download and install

Download `LectureCaption-0.3.0-macOS-arm64.zip`, check `SHA256SUMS.txt`, extract, and drag **Lecture Caption.app** into **Applications**. Requires Apple Silicon and macOS 14+. This is an **ad-hoc signed, not Apple-notarized** early release; macOS may require its Open Anyway flow. Get your own Groq key and test it in the app. Free API tiers are quota-limited and can change.

源码、构建脚本和第三方许可同时公开。下载 macOS-arm64 ZIP，核对校验和后解压，拖入“应用程序”。首次使用请在应用里验证并保存自己的 API key。

### Validation and limitations

Automated checks use synthetic audio and mocked API responses. The original pipeline was confirmed by its user on an M5 Mac to produce original text, translation and notes. This does not establish long-lecture stability or all conferencing-device combinations.

Chunked latency; one input at a time; shared credential for both configured endpoints; pause discards untranscribed audio; the built-in reader preserves LaTeX source without typesetting. Notes can misrecognize notation and cannot reconstruct silent board content. No automatic updates or app-owned cloud backend.

The source archive accompanies the binary and includes build instructions and component notices. SHA-256 sums are for transport verification, not independent publisher identity.
