# Lecture Caption v2.4.5

首个 **Developer ID 正式签名与 Apple 公证版**，通过 GitHub 独立分发，未上架 Mac App Store。

## 下载和开始

[![下载 Mac 版（M 系列）](https://img.shields.io/badge/下载-Mac_M系列_v2.4.5-2877E1?style=for-the-badge&logo=apple)](https://github.com/superboycyc-dot/lecture-caption/releases/download/v2.4.5/LectureCaption-2.4.5-macOS-arm64.zip)

1. 下载 ZIP、解压并打开 Lecture Caption.app。
2. 不在应用程序中时，点击“安装到应用程序并打开”；已安装则直接进入。
3. 按首次指南连接 Groq，准备 Apple 本地资源，再开始收音。首次仍可能出现系统下载来源确认和麦克风权限提示。

签名主体为开发团队账号主体；软件作者仍为 Yichen Chen。证书与私钥未放入仓库。请使用本页的正式安装包，不要把 CI 的临时构建当作公证版。

## 本次更新

- 主应用、原生组件及打包依赖使用 Developer ID Application 签名，启用 Hardened Runtime 和安全时间戳。
- Apple 公证通过后装订票据，发布前通过 Gatekeeper 检查。
- 已签名安装版更新时验证同一开发团队及新版公证，防止回退到临时签名包。旧版临时签名应用可通过原有 GitHub 与校验和流程迁移。
- 保留 2.4.4 的安装循环修复、自动 PDF 保存、公式兼容与自动笔记功能。

如仍安装失败，先退出旧程序，再将新版拖到应用程序替换一次。笔记和设置独立存储，不需重置钥匙串或重新购买开发者会员。

## 钥匙串提示

初次使用新签名身份，macOS 可能再次询问是否允许读取“Lecture Caption API Key”。请输入 Mac 登录钥匙串密码（不是 Groq key 或 Apple 登录密码），由系统验证。开发者不会收到这个密码。
