# Lecture Caption v2.4.2

免费开源的 macOS 课堂字幕与 Markdown 笔记工具。适用于 Apple Silicon（M 系列）Mac，macOS 14+；Apple 本地翻译需要 macOS 15+。

## 下载和开始

> 🔴 **首次打开容易被 macOS 拦截，请根据下方图解一步步完成设置。**

[![立即下载 Mac 版（M 系列）](https://img.shields.io/badge/%E7%AB%8B%E5%8D%B3%E4%B8%8B%E8%BD%BD-Mac_M%E7%B3%BB%E5%88%97_%C2%B7_v2.4.2-2877E1?style=for-the-badge&logo=apple&logoColor=white)](https://github.com/superboycyc-dot/lecture-caption/releases/download/v2.4.2/LectureCaption-2.4.2-macOS-arm64.zip)

点击上方蓝色按钮直接下载 ZIP，无需 GitHub 账号。下载后解压，拖入“应用程序”即可。

1. 点击上方蓝色按钮下载，解压后把 **Lecture Caption.app** 拖到“应用程序”。无需 Python、终端或服务器。
2. 打开应用；如 macOS 提示无法验证开发者，在核对本仓库来源后，到“系统设置 → 隐私与安全性”点击“仍要打开”。当前应用为本地签名，尚未 Apple 公证。
3. 首次指南中连接 Groq，注册/登录 → Create API Key → 复制，回到应用点“下一步”。每位用户使用自己的 key，自动保存在 macOS 钥匙串。Groq 免费额度受账号限制。
4. 按系统提示授权，跟着箭头教学选音源、点开始。教室用麦克风，会议/视频用电脑音频。跳过 Groq 可使用本地字幕，但无法自动整理笔记。

## 看到“Keychain 想要使用机密信息”怎么办？

这是 macOS 的钥匙串授权窗口：软件想读取你之前保存的 **Lecture Caption API Key**，这样下次打开就不用重新输入 Groq key。这里的“机密信息”指这个已保存的 key。

<img src="https://raw.githubusercontent.com/superboycyc-dot/lecture-caption/v2.4.2/docs/install/keychain-prompt.png" width="680" alt="macOS 钥匙串弹窗：Keychain 请求读取 Lecture Caption API Key，可选择始终允许、拒绝或允许">

**先核对条目名称是“Lecture Caption API Key”**，且你正在打开官方版本的 Lecture Caption。弹窗中的 **Keychain** 是本软件随附的钥匙串辅助程序名称。

1. 密码框要求的是 **“登录”钥匙串的密码**，通常就是你解锁这台 Mac 的登录密码，**不是 Groq API key，也不是 Apple ID 密码**。如果你曾单独修改钥匙串密码，请使用对应密码。
2. 想先授权这一次，点 **“允许”**；下次读取时可能再次询问。
3. 确认来源可信、希望以后少弹窗，可以选择 **“始终允许”**，让这个辅助程序以后读取该条目时不再逐次确认。更新程序后，系统仍可能要求重新授权。
4. 不想授权，可以点 **“拒绝”**。本次无法自动读取已保存的 key，仍可在软件设置中手动填写；不使用 Groq 时也可选择本地字幕，但无法自动整理笔记。

密码仅在 **macOS 系统弹窗** 中输入，由系统验证；本软件不会接收这个 Mac 密码。授权后软件会取得该 API key 来调用接口。不要把 Mac 密码填到软件的 API key 栏、Groq 网页或发给任何人。这个操作是在授权读取上述条目，不是要求你关闭钥匙串保护。

按钮含义可参阅 [Apple 官方说明：允许 App 访问钥匙串](https://support.apple.com/guide/mac-help/kychn002/mac)。

## 本次更新

- Groq 配置窗口放大操作步骤：Create API Key → Display Name 填 `Lecture Caption` → Expiration 保持 `No expiration` → 生成后复制完整 key，返回应用验证保存。
- Apple 英文识别和英中翻译资源分别准备，一个失败不阻止另一个下载；Groq 配置完成后提醒检查本地备用，设置内可单独打开下载及听写设置。
- 结束整理后保留应用内 Markdown，自动将 PDF 保存到桌面或设置中的默认目录；显示实际保存路径，并提供“另存为 MD / 另存为 PDF / 完成”。同名笔记不会覆盖先前 PDF；保存失败会明确说明。
- 常用 LaTeX 数学公式离线显示、双击编辑并嵌入 PDF；Markdown 保留原始语法。支持 `\[...\]`、`\(...\)`、`$$...$$` 和 `$...$`，不支持的 TeX 宏保留源码，避免公式丢失。
- 自动笔记关闭时明确提示；整理失败显示原因。修复笔记框仅获得焦点就一直阻塞整理的问题，实际编辑保存并停止输入后恢复。

**使用提醒：** Groq 识别/翻译与自动笔记是独立开关。在设置中勾选“自动整理并保存 Markdown 笔记（Groq）”才能周期整理；本次尚在内存中的已识别内容可通过笔记右上角“⋯ → 立即整理”补整理。每位用户使用自己的 Groq key，免费额度受供应商限制。

用量分享仍以首次明确授权为前提，可在设置关闭；只上传数字，不发送录音、原文、译文、笔记或 API key。规则与网络诊断边界见[软件使用规则](https://github.com/superboycyc-dot/lecture-caption/blob/v2.4.2/docs/SOFTWARE_RULES.zh-CN.md)。

105 项合成数据测试通过。真实音源/供应商可用性取决于设备权限、语言包、网络及账号；未用用户课堂内容或密钥进行发布测试。
