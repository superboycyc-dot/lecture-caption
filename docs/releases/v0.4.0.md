# Lecture Caption v0.4.0

A single workspace replaces the three-window layout. Notes appear on the left and bilingual caption history on the right. The newest segment is highlighted and scrolls smoothly; reading older text pauses follow until “回到最新”.

A single compact top toolbar contains logo, input source, recognition/translation backends, English/Chinese/bilingual display, Start/Pause, Stop and a small settings icon. The level meter and locally counted API usage are at the bottom. Note hints disappear after the first content; refresh/folder icon buttons remain in the note pane’s top-right corner. Settings open as a dialog. Opacity, backend, caption-language and typography preferences survive restarts.

Apple local mode is optional: on-device English speech recognition is experimental; English-to-Chinese translation uses Translation.framework on macOS 15+ with language assets installed. Prepare translation packs in Settings. Audio never silently falls back to cloud. Translation and recognition remain chunked near-real-time, not word-by-word interpretation. Local speech uses roughly 2–3 second segments plus recognition/translation time.

With both Apple backends selected and automatic notes disabled, captions require no API key. Structured Markdown notes still use your Groq key and send recognized text to Groq. Course glossary prompts apply to cloud recognition; Apple recognition currently uses general English dictation.

## Requirements and verification

- Apple Silicon, macOS 14+ for cloud mode; macOS 15+ for Apple translation. Local English speech depends on system support/resources and speech-recognition permission.
- Application and release ZIP are ad-hoc signed, not notarized. Python and runtime libraries are bundled. Keys, personal recordings, notes and config are excluded.
- Regression tests use synthetic audio and mocked providers; real classroom/meeting accuracy is not implied. Apple translation was checked on macOS 26.6 using a synthetic CS sentence. Microphone/end-to-end local recognition requires user verification.

Download `LectureCaption-0.4.0-macOS-arm64.zip`, extract and drag the app into Applications, replacing the old app after closing it. Existing Keychain credentials and app-data notes remain available. SHA256SUMS.txt covers both binary and source ZIPs.

When Groq returns rate-limit headers, the main window also displays the latest server request/token snapshot with its model and timestamp. This is not a billing balance or a live combined quota for all models. See [Groq rate-limit headers](https://console.groq.com/docs/rate-limits).
