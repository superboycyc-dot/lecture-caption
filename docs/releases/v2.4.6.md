# Lecture Caption v2.4.6

## 更新内容

- 笔记约每 30 秒追加一次，每 5 分钟将此前全部笔记整合替换；10 分钟整合包含 0–10 分钟的内容。
- 增量整理只发送新增原文和近期笔记，输出预算降至 1800 token；失败积压分批处理，保留完整本地原文。
- 笔记框左下角持续显示整理失败及具体原因，直到下一次笔记请求成功。诊断不包含密钥、原文或服务端响应正文。
- 网络、超时、429 和临时服务错误最多自动重试两次，指数退避并遵守服务器等待时间；长限流进入冷却，密钥/权限错误不重试。暂停/结束取消转录重试。
- 结束课程时将转录原文 Markdown 自动保存到默认 PDF 导出目录，增加“另存转录”按钮。
- 沿用 Developer ID 签名、Apple 公证和同团队更新验证。

## 下载与安装

下载 `LectureCaption-2.4.6-macOS-arm64.zip`，解压后打开应用。旧版本可通过应用内检查更新安装。首次仍可能出现 macOS 下载来源确认、录音权限或钥匙串授权提示。

应用为 Apple Silicon、macOS 14+；Apple 本地翻译要求 macOS 15+。Groq 账号额度及模型限制仍适用，不会自动切换付费服务。
