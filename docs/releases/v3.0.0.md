## 软件介绍

面向英语课堂、线上课程与会议学习的 Mac 双语字幕和实时笔记工具。支持麦克风/电脑音频、英文原文与中文翻译、Apple 本地或 Groq 模型、笔记编辑与公式预览、Markdown/PDF 和转录原文导出。

- 每 30 秒追加新增笔记，每 5 分钟整合此前全部内容。
- Groq 整理失败显示具体原因，临时错误自动退避重试，完整原文保存在本机。
- 结束时自动保存 PDF 和转录 Markdown，“另存转录”可单独保存原文。
- 密钥使用 macOS 钥匙串；无原始录音文件，不在点击开始前收音。

## 安装

1. 点击上方按钮下载 DMG，双击打开。
2. 把 **Lecture Caption** 拖到右侧 **Applications（应用程序）**。升级时先退出旧版，再确认替换。
3. 推出安装磁盘，从“应用程序”打开，按首次指南配置权限与模型。

适用于 Apple Silicon M 系列和 macOS 14+（Apple 本地翻译要求 macOS 15+）。DMG 与内部应用均使用 Developer ID 签名并通过 Apple 公证；首次可能出现正常的来源确认、录音权限和钥匙串弹窗。无需 Python 或终端。
