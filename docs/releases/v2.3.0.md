# Lecture Caption v2.3.0

免费开源的 macOS 课堂字幕与 Markdown 笔记工具。适用于 Apple Silicon（M 系列）Mac，macOS 14+；Apple 本地翻译需要 macOS 15+。

## 下载和开始

[![立即下载 Mac 版（M 系列）](https://img.shields.io/badge/%E7%AB%8B%E5%8D%B3%E4%B8%8B%E8%BD%BD-Mac_M%E7%B3%BB%E5%88%97_%C2%B7_v2.3.0-2877E1?style=for-the-badge&logo=apple&logoColor=white)](https://github.com/superboycyc-dot/lecture-caption/releases/download/v2.3.0/LectureCaption-2.3.0-macOS-arm64.zip)

点击上方蓝色按钮直接下载 ZIP，无需 GitHub 账号。下载后解压，拖入“应用程序”即可。

1. 点击上方蓝色按钮下载，解压后把 **Lecture Caption.app** 拖到“应用程序”。无需 Python、终端或服务器。
2. 打开应用；如 macOS 提示无法验证开发者，在核对本仓库来源后，到“系统设置 → 隐私与安全性”点击“仍要打开”。当前应用为本地签名，尚未 Apple 公证。
3. 首次指南中连接 Groq，注册/登录 → Create API Key → 复制，回到应用点“下一步”。每位用户使用自己的 key，自动保存在 macOS 钥匙串。Groq 免费额度受账号限制。
4. 按系统提示授权，跟着箭头教学选音源、点开始。教室用麦克风，会议/视频用电脑音频。跳过 Groq 可使用本地字幕，但无法自动整理笔记。

## 本次更新（自 2.0.0）

- 导入已有 Markdown 接着上一课记录；在笔记框直接编辑，支持标题、粗斜体、列表、删除线、==高亮== 和 Command 快捷键。
- 自动整理连续课堂原文，每 1–5 分钟二次整理全文并生成笔记名称；保护手动修改不被旧 AI 响应覆盖。
- 结束后选择保存 Markdown 或导出 PDF，再选择路径；记住上次目录，保留内部备份。
- Groq 优先的首次配置、Apple 备用资源准备，以及真实主窗口上的灰色遮罩和白色箭头教学。
- H 荧光笔图标、左对齐三项菜单（查看源代码 / 立即整理 / 打开文件夹）、可折叠高级设置。
- 关于窗口、开发者信息、官方 GitHub 一键更新；默认自动更新，录音、编辑、设置或教学期间不会自动安装重启。

- 更新 certifi 至 2026.10.19，修复证书信任根安全公告 GHSA-6q48-6c7w-9gw2。
