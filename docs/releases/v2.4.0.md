# Lecture Caption v2.4.0

Optional numeric usage sharing appears alongside the existing one-action setup. It is unchecked by default and can be disabled in Settings. Counts include recording sessions, capture duration and source/translation word/character lengths, without audio, text, notes, credentials or stable device identifiers.

The client stores cumulative snapshots locally in SQLite, retries without discarding unacknowledged revisions, ignores stale acknowledgements for newer data and clears pending rows on opt-out. Networking and duration checkpoints run independently. No background launch service is installed; closed apps resume retry on the next launch. Network-path anonymity is not promised because Funnel/upstream diagnostics may see IP addresses.

Public HTTPS uploading is enabled after [independent tailnet-external acceptance](https://github.com/superboycyc-dot/lecture-caption/actions/runs/40411300895) and receiver restart persistence verification. Sharing is still unchecked by default and requires explicit consent. No Tailscale installation or server configuration is required for ordinary users. The test runner checked retries, revision corrections, conflict rejection, rate limits and inaccessible admin/database routes using fictional numbers only. Existing v2.3.0 assets and tags are unchanged.
