# Lecture Caption 3.2.0

- 笔记编辑改为离线 Vditor 即时渲染，支持 Markdown 表格、行内和块级公式；公式使用 KaTeX，基准字号与正文一致。
- PDF 采用相同的网页排版和离线公式字体。
- 默认每 60 秒追加新增内容，每 600 秒整合全部笔记；手动立即整理、结束时最终整理仍可提前执行。
- 编辑暂停、切换源码、旧异步响应和中文输入均有保存保护，离开编辑区不额外调用整理。
- 现有安装首次升级迁移到 1/10 分钟节奏，之后保留高级设置中的整合间隔。

正式安装包使用 Developer ID 签名和 Apple 公证，提供 DMG 安装器及供软件内更新使用的 ZIP。验证使用合成课堂内容，不代表真实录音/API 测试。

下载 DMG 后拖到“应用程序”，或在已有软件内检查更新。笔记编辑组件和公式字体随应用离线提供，无需额外安装；网页运行库会增加应用体积。
