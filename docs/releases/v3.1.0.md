# Lecture Caption 3.1.0

## 新功能
- 笔记空白区新增“打开历史”：浅蓝卡片入口，直接在软件内选择最近的笔记，无需访达。
- 历史列表显示标题、日期时间和正文前 15 字；按最近修改时间排序，点击窗口外或按 Esc 关闭。
- 查看历史不修改原文件；编辑或继续记录时保存续写副本。
- 新版使用规则说明统计上传连接 IP 的用途、30 天保留期及退出方式；升级后须重新明确同意才恢复统计上传。

## 安装
下载 **LectureCaption-3.1.0-macOS-arm64.dmg**，双击后将应用拖到“应用程序”。升级前先退出旧版，再按提示替换，笔记和设置保留。支持 Apple Silicon、macOS 14+。

DMG 与内部应用均已通过 Developer ID 签名和 Apple 公证。应用 ZIP 同时保留，供旧版应用内更新使用。

## 验证与范围
客户端与接收端自动测试、macOS 构建与隔离启动检查、DMG 布局与签名公证验证通过。未使用真实录音或付费模型进行本轮验证。

本次发布包含配套统计接收端源码，但不部署线上服务器；连接 IP 入库需运营方另行部署新版接收端。旧版后台仍可接收数字统计。
