# Roadmap

Planned work, not promised delivery dates:

- Preserve/drain the final incomplete audio segment on explicit Finish, while keeping immediate Pause available.
- Improve partial captions, terminology continuity and mathematical notation confidence.
- Separate credentials for speech and text providers, with tests for each endpoint.
- Persist window positions, opacity and Pin preferences.
- Render LaTeX and add optional user-selected lecture context.
- Add proven home-server deployment profiles after testing the exact hardware/software stack (including Orange Pi AIpro).
- Broaden conference/microphone and full-lecture battery/latency measurements.
- Developer ID signing/notarization when the owner provides an appropriate account and certificates.

Current behavior is documented in README and the user guide; no roadmap item is advertised as already working.
