# 使用指南

## 3.0.0 DMG 安装

1. 下载官方 `LectureCaption-3.0.0-macOS-arm64.dmg`，双击打开。
2. 把左侧 Lecture Caption 拖到右侧 Applications（应用程序）。升级时先退出旧应用，再由 Finder 确认替换。
3. 复制完成后推出安装磁盘，从“应用程序”打开软件。

DMG 和内部应用都需通过签名、公证及 Gatekeeper 检查。正常首次来源确认、麦克风/系统音频和钥匙串权限由 macOS 处理；不要把“已损坏”当作正常安装步骤。若异常，先重新下载并核对 SHA-256，再提供 `codesign` 和 `spctl` 的验证结果，不需要关闭系统安全保护。

ZIP 作为旧版本应用内更新的兼容资产保留；新用户优先使用 DMG。


首次安装后无法打开？请先看[Mac 首次打开四步图解](INSTALL.zh-CN.md)，跟着红框操作后再继续下面的配置。

## 第一次使用

首次设置底部、连接按钮上方有“同意《软件使用规则》”。蓝色链接打开规则弹窗；未勾选不能继续配置或开始收音。首页明确标注同时授权数字用量分享，未勾选不能继续；无需第二个勾选，设置里可随时关闭分享。规则勾选行只在第一页显示，后续配置页不重复。关闭向导也不能绕过首次接受要求。可在“关于”中重新查看规则；已有笔记仍可查看和导出。

1. 打开官方 [Groq API Keys](https://console.groq.com/keys)，完成注册/登录。
2. 点 **Create API Key**，命名后复制 key；不要发给项目维护者或提交到 GitHub。
3. 在应用的 **Groq API key** 栏粘贴。点 **测试 API**。
4. 勾选“验证成功后保存到钥匙串”，成功后自动保存，也可手动“保存 key”。
5. 选择输入。教室现场选麦克风，视频/会议选电脑内部音频。
6. 点开始收音，允许对应的 macOS 权限。

保存过 key 后若出现“Keychain 想要使用机密信息”，请看[钥匙串授权图解](INSTALL.zh-CN.md#看到keychain-想要使用机密信息怎么办)，了解密码要求和三个按钮的区别。

## 窗口

主界面左侧笔记、右侧双语历史，可拖动分隔线调宽度。顶部直接选择输入、识别/翻译方式及字幕语言，使用开始/暂停与停止按钮；音量和用量在底部。置顶按钮已删除；不透明度可在设置中调整，偏好会保存。最新字幕高亮；向上浏览时暂停跟随，点击“回到最新”恢复。设置点击后弹出，可配置 key、识别/翻译方式、笔记、术语和字号。

## 笔记

默认每45秒整理一次，也可“立即整理”。笔记窗口有阅读和 Markdown 源码两页；“打开笔记文件夹”定位 `notes.md`。笔记围绕实际听到的内容提炼定义、假设、推导、算法和复杂度。请核对公式、代码与【待核对】内容。预览保留 LaTeX 原码，不排版公式。

已识别的原文会即时保存。网络/模型错误时尚未整理的原文保留在笔记尾部。为了保持实时，积压的音频会被跳过，并标记缺失。暂停前若要保留最后一句，请等它显示成字幕再暂停；暂停会丢弃尚未识别的音频，已有转写的笔记整理可能继续。

## 保存和隐私

笔记、原文/翻译事件、日志：`~/Library/Application Support/Lecture Caption/`。不保存原始录音。音频和文字发往所选 API；使用前确认课堂/会议允许这样的处理。

key 存储在本机 macOS 钥匙串，不写普通配置，不启用 iCloud 同步。“删除已保存 key”只删除本机记录，不撤销 Groq 上的 key。锁定钥匙串或拒绝系统授权后，可手动输入。

## 家用服务 / 香橙派

将仓库中的 `config.example.json` 复制为应用数据目录的 `config.json`，更改模型和服务地址，重启应用。它需要 OpenAI 兼容语音/聊天接口；当前只用一个 key，配置到不相关服务器会把该 key 发给那里。不同地址组合有独立的钥匙串记录。跨外网访问家里设备的 VPN、昇腾适配与模型部署不在本应用内实现。

更详细的接口要求、限制和排错见 [English guide](USER_GUIDE.md)。

## Apple 本地字幕

设置中分别选择 Apple Speech 和 Apple Translate，先点击“准备 Apple 英中翻译语言包”完成系统下载。允许语音识别权限；英文听写资源需由系统安装。Apple 翻译需 macOS 15+。关闭自动笔记可不填 API key；开启笔记仍需 Groq，且会发送原文。资源缺失时提示错误，不会自动上传音频到云端。本地模式仍按约2–3秒分段，并非逐字同传。

Groq 请求返回限额响应头时，主界面还会显示最近一次服务端剩余请求/Token 快照，标明模型和时间；它不是费用余额，也不代表所有模型的实时总额度。

顶部一行包含音源、识别/翻译后端、纯英文/纯中文/双语输出、开始/暂停、停止及设置图标。底部显示音量和用量。笔记框可直接输入；右上角“…”可切换 Markdown 源码、立即整理 或打开文件夹。字幕语言选择只改变显示，不会删除历史译文或改变当前翻译后端。

macOS 26+ 使用新的 SpeechAnalyzer 本地识别引擎；语音模型与系统“听写”开关不是同一个配置。应用设置中新增“准备 Apple 英文语音资源”，可直接检查并下载所需模型。macOS 14/15 仍使用旧版 Speech 接口。本地音频不回退到云端。

连贯字幕模式：右侧不再使用分段卡片。每段显示起止时间、黑色英文与蓝色中文，当前段落加亮。Apple/Groq 均周期性重新识别当前整段音频并重译完整原文，修正早期断词，停顿后才换段；连续语音最长约24秒成一小段。预览更新时保留上一版译文，直到新译文返回。笔记只整理已完成段落，暂停时保留最后草稿。Groq 会处理重复的累积音频，因此实际语音额度消耗高于单次切片模式；不会自动换付费后端。时间范围为采音分段的近似时间，不是逐词对齐。

录音中可修改音源、识别与翻译方式：纯翻译切换保留收音与原文识别，重译当前段落；音源或识别方式切换会保存已识别草稿、重新连接输入并丢弃旧会话迟到响应。输入重连期间未识别尾音可能缺失，文档保留缺失提示。右下音量旁绿点表示收音、灰点表示停止、红色感叹号表示音频设备错误（悬停查看）。当日 API 余量与本机24小时语音请求数紧邻显示，不显示分钟数或处理耗时。回到最新是覆盖在右下角的32px小按钮，上翻出现，到底自动隐藏，不占用内容布局。

笔记约每 30 秒追加新增内容，每 5 分钟整合此前全部笔记（10 分钟时包含 0–10 分钟内容）。增量请求按完整原文段落分批，目标上限为新增原文 6000 字符、近期笔记 2400 字符，输出上限 1800 token；单个超长段落可能超过分批目标。整合时发送完整笔记，并按文档长度分配 1800–6000 token 输出预算。本机保留全部转录原文；开启笔记可能发送当前课堂此前尚未整理的内容。长课时仍受账号额度和模型限制。


## 续课、编辑与另存

笔记框左上角文件夹图标导入 UTF-8 Markdown；直接在笔记框中增删改，编辑后自动保存。导入文件保持原样；应用内更改前快照仍留在会话目录。导入内容作为已有笔记提供给后续整理；开启自动笔记后会发送给所选笔记服务。

设置中的自动二次整理间隔为 1–5 分钟，默认 3 分钟；内容有变化才运行，自动梳理整份笔记并生成课程主题标题，没有手动 revise 按钮。需开启自动笔记并提供 API key，会额外消耗文本模型额度。点击结束会等待最后整理和必要的二次整理，随后自动保存 PDF 到默认目录，并提供“另存为 MD / 另存为 PDF / 完成”；另存默认文件名来自主题标题，并记住上次成功另存目录。完成或取消另存不会删除应用内备份。

## 关于和软件更新

点击顶部软件 logo 查看当前版本、开发者 Yichen Chen、邮箱、GitHub 和下载地址。默认自动更新：启动和每6小时检查官方正式发布并下载校验新版；仅在空闲且未创建课堂会话时自动安装重启。有笔记或正在录音时保留当前工作，结束并另存后可点击“安装更新并重新打开”。受保护的应用目录可能弹出 macOS 管理员授权；取消授权会重新打开原应用。安装不会移动应用数据或钥匙串。设置/关于中的“自动更新”可以关闭。源码运行不替换应用；安装版需放在系统或当前用户的“应用程序”目录。


## 首次使用

第一次打开说明 Groq 用于课堂识别、翻译和自动笔记。点击“连接至 Groq 取得 API”，软件先自动准备 Apple 本地备用能力和当前音源权限，再打开内置官方注册/key 页面：登录/注册 → Create API Key → 复制；回到向导点“下一步”，验证并保存到钥匙串。空输入框会在明确点击“下一步”时读取一次剪贴板；不会持续监听。第三方登录如不支持内置页面，可在默认浏览器继续。Apple 备用资源准备失败仍可继续配置 Groq。账号创建、验证码、苹果权限确认仍需本人完成。

只有明确点击“跳过（无法使用笔记功能）”才使用 Apple 本地字幕并关闭笔记。设置过程不开始收音。配置完成点“下一步”，主窗口出现灰色遮罩，白色箭头逐项指向开始、音源、模型、导入、编辑、高亮、菜单、结束与设置；可下一步或跳过，教学不会替你点击录音。

识别更新默认8秒、笔记默认45秒、二次整理默认3分钟；不必修改。设置中的“高级设置”点击展开模型、更新间隔等参数。自动更新默认开启，用户可关闭。设置和关于中可重新打开教学。

## 直接编辑与格式

笔记框直接编辑，顶部标题也可改名。工具栏提供 B、I、H1/H2/H3、列表、高亮和删除线；“…”只含查看源代码、立即整理 和打开文件夹。Command+B 加粗、Command+I 斜体、Command+H 高亮、Command+Shift+X 删除线；Command+Option+1/2/3 切换标题，Command+Shift+7/8 创建编号/无序列表。快捷键作用于笔记编辑区。输入 `**加粗**`、`*斜体*`、`==高亮==`、`~~删除线~~` 后会显示对应格式，Markdown 标题/列表前缀加空格可直接输入；源码视图可编辑原始 Markdown。代码中的符号保持字面值。未修改的导入原文保持不变，富文本编辑后会规范化为 Markdown。LaTeX 保留文本，不做公式排版。

编辑自动备份，离开编辑区后 AI 继续整理；不会用旧响应覆盖新修改。结束时自动保存 PDF，随后可选“另存为 MD”或“另存为 PDF”再选路径，也可直接“完成”，原备份始终留存。只导入/手写笔记也可以点结束导出，无需先录音或填写 key。


## 可选用量分享（2.4）

首次设置用一个未预勾选的“同意《软件使用规则》并分享用量统计”明确取得授权，必须勾选才能继续；无需单独的统计选项。设置里可随时关闭分享，不影响字幕和笔记。只统计同意之后的录音次数、有效收音时长、原文及译文词数/字数。不会上传录音、文字、笔记、API key 或设备标识。暂停继续算同一节课，重复识别和重译会修正原统计。

同意后先写本机 SQLite 队列；上传失败或确认无效会保留，联网/下次打开时继续重试。软件关闭时不另启后台常驻程序。设置里关闭分享会停止收集/后续上传并清除本机队列，在途请求可能已到达服务器。不要把此功能描述为整条网络链路匿名：上游网络服务可能记录连接 IP。

2.4 正式版的公网 HTTPS 接口已通过独立外网验收；普通用户无需安装 Tailscale 或填写服务器地址。首次明确勾选授权后才会自动同步；状态在设置中显示，不影响正常收音。[查看独立公网验收](https://github.com/superboycyc-dot/lecture-caption/actions/runs/40411300895)。


### Groq 首次配置与 Apple 本地备用

按照窗口上方的大字步骤操作：登录或注册 Groq，点 **Create API Key**；**Display Name** 填 `Lecture Caption`，**Expiration** 保持 `No expiration`。点 Submit / Create API Key 后，一定要复制完整 key，再返回应用点“下一步：验证并保存 key”。完整 key 之后可能无法再次查看。第三方登录无法在内嵌页面完成时，点“在默认浏览器继续”。

Groq 连接后，建议点击“检查 / 下载 Apple 识别与翻译资源”。英文识别与英中翻译是两套独立资源；出现系统下载窗口时请完成下载并等待。一个下载失败不会阻止另一个继续准备。失败时会分别说明已完成及未完成的项目，可重试。macOS 15–25 的英文识别需在系统设置 → 键盘 → 听写中添加英语（美国）；可直接点击“打开系统听写设置”。macOS 26+ 可由应用下载英文识别资源。英中翻译需要 macOS 15+。

日后可在应用“设置”中一键准备，也可单独点击英文识别下载、英中翻译下载或打开听写设置。准备不会开始录音，也不会改掉已选的 Groq 模型。


### 结束后的自动保存与另存

结束整理后，应用内继续保留 Markdown 备份，同时自动生成 PDF，默认保存到桌面。可在“设置 → PDF 自动保存位置 → 更改…”选择其他目录。自动文件名包含时间，避免同名笔记被覆盖；另存目录与自动目录分别记忆。自动保存成功后显示实际路径，并提供“另存为 MD”“另存为 PDF”“完成”。完成无需再选择路径。若目录不可写，明确提示失败，可另存，Markdown 备份仍保留。

### 数学公式

支持 `\[ ... \]`、`\( ... \)`、`$$ ... $$`、`$ ... $` 中的常用分式、根号、上下标、积分和求和，离线显示并嵌入 PDF。双击渲染后的公式可修改 LaTeX，也可从“查看源代码”编辑；Markdown 导出保留原始公式语法。代码块内的公式示例保持原样。渲染器支持 TeX 数学语法的子集，不等同于完整 LaTeX；不支持的宏保留源码，不丢弃公式。


### 2.4.3 一键安装
下载 ZIP 后解压、打开应用。完成 macOS 首次安全确认后，点“安装到应用程序并打开”，软件自动复制并验证，退出下载副本后打开已安装版本。权限不足时由 macOS 请求管理员授权；原下载文件不删除。若已有安装，点击“打开已安装版本”后在关于窗口检查更新。也可“稍后（继续使用）”。下载中的文件不能自行运行或移动，系统安全拦截不能自动绕过。

## 2.4.6 故障提示与转录导出

笔记约每 30 秒追加新增内容，每 5 分钟整合此前全部笔记（10 分钟时包含 0–10 分钟内容）。增量请求按完整原文段落分批，目标上限为新增原文 6000 字符、近期笔记 2400 字符，输出上限 1800 token；单个超长段落可能超过分批目标。整合时发送完整笔记，并按文档长度分配 1800–6000 token 输出预算。本机保留全部转录原文；开启笔记可能发送当前课堂此前尚未整理的内容。长课时仍受账号额度和模型限制。

Groq 整理失败提示固定显示在笔记框左下角，并显示安全的具体原因（超时、429、401/403、模型地址错误、输出不完整等），直到下次笔记请求成功。网络和临时服务错误最多退避重试两次；429 遵守等待时间，长等待不会反复请求。密钥/权限错误不自动重试。暂停或结束取消转录重试。结束时 PDF 和转录原文 Markdown 分别保存到默认 PDF 目录，任一导出失败会单独提示；“另存转录”可随时导出已识别原文。
